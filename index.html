국장 “전일 종가 ≤ 2만원 & 전일 Top50(랭킹)” 익일 매수 자동매매 개발을 위한 Codex 작업지시서

Executive Summary

본 문서는 “전일 종가 2만원 이하”이면서 “전일 기준 순위(Top 50)” 조건을 만족하는 종목을 익일에 매수·매매하는 전략을 거래비용(세금·수수료)·슬리피지 포함 기준으로 검증하고, 자동매매 프로그램(데이터 파이프라인→랭킹→신호→백테스트→OMS 시뮬→실계좌 연동)으로 구현하기 위한 실무 지시서입니다.

정규시장 시간(호가접수 08:30~15:30, 매매거래 09:00~15:30) 기준으로 배치/실시간 경계를 설계하고, 시장별 증권거래세 및 유가증권시장 농어촌특별세를 비용모델에 반영합니다.

Codex에 붙여넣을 단계별 작업 지시서

[역할] 너는 Python 기반 퀀트/자동매매 엔지니어다. 아래 요구사항을 충족하는 R&D + 백테스트 + OMS 시뮬 + 실계좌 연동 프레임워크를 생성하라.

  • 필터: 전일 종가 ≤ 20000, 전일 랭킹 Top 50
  • 랭킹: value/volume/mcap 선택 가능
  • 진입: open/open_plus_minutes/after_volume_threshold
  • 청산: close/time_exit/tp_sl/next_close
  • 리스크: max_positions, exposure, per_symbol_cap, daily_loss_limit

필수 기능 목록

  1. 데이터 수집/정제 파이프라인
  2. 랭킹 계산 및 신호 생성
  3. 백테스트 엔진(비용/슬리피지 플러그인)
  4. OMS 시뮬레이터(상태머신·부분체결·타임아웃)
  5. KIS 실계좌 어댑터 샘플(토큰/시세/주문/체결)
  6. CLI/운영문서/테스트/CI
