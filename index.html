실거래/테스트 안내

이 화면의 분석/백테스트는 학습용입니다. 실거래 버튼은 로컬 서버가 Binance API로 주문을 전송할 때만 동작하며, 테스트넷을 사용하면 실제 자금이 아닌 모의 자금으로 체결됩니다.

“가용 USDT”와 자동매매 시뮬레이션은 화면 내 계산용 값이며, 실제 계정 잔고와는 연결되지 않습니다.

예측 로직 요약

  • 단기/장기 이동평균과 RSI를 함께 사용해 추세 방향을 계산합니다.
  • 상승 추세면 “롱 관찰”, 하락 추세면 “숏 관찰”로 표시합니다.
  • ATR 기반 변동성과 최소 목표 거리 기준으로 목표가/손절가 범위를 제안합니다.
  • 실시간 시세는 바이낸스 공개 API의 최근 캔들 종가를 사용합니다.

주의 사항

  • 이 도구는 실제 매매를 대신하지 않습니다.
  • 실제 주문, 손절/익절 관리, 수수료, 슬리피지는 별도로 고려해야 합니다.
  • 자동매매는 서버에서 API 키를 안전하게 보관하고 주문을 실행해야 하므로, 브라우저 단독으로는 처리할 수 없습니다.
  • 표시되는 진입/익절/손절 가격은 학습용 참고 값이며, 손익을 보장하지 않습니다.
