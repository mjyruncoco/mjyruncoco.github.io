국내 주식 제안형 자동매매 보조 프로그램 설계 및 구현 방안

제안형 키움 REST API 리스크 관리 과적합 방지

Executive Summary

본 설계는 현재가 1만원 이하이면서 유동성이 충분한 종목을 1차로 선별한 뒤, 단기(1~30거래일) 내 10% 이상 상승 확률을 추정해 사용자에게 매수가·목표가·손절가·권장수량을 “자동 주문”이 아닌 “제안” 형태로 제공하는 구조를 목표로 합니다.

핵심 설계 요약

1) 데이터 파이프라인

  • /oauth2/token 기반 인증 토큰 관리
  • /api/dostk/rkinfo로 후보군 1차 축소
  • /api/dostk/mrkcond (ka10004)로 호가·잔량 수집

2) 유동성 필터

  • 거래대금(절대값 + 퍼센타일)
  • 스프레드(틱 단위), 호가 깊이(1~3호가)
  • OBI/Amihud ILLIQ 결합 점수

3) 예측 모델

  • 1차: RandomForest / XGBoost
  • 2차: LSTM (확장 실험)
  • 라벨: 고정지평 + 트리플 배리어 병행

4) 리스크/추천 규칙

  • 손절: ATR 기반(1.5~2.5 ATR) vs 고정%
  • 목표가/손절가/매수가는 틱 규칙 반영
  • 수량: R-리스크 기반 제안

검증 및 운영 원칙

  • 불균형 분류 지표로 PR-AUC(average precision) 우선 사용
  • 확률 예측값 캘리브레이션으로 제안 일관성 확보
  • Purging/Embargo, CPCV, PBO로 과최적화 위험 통제
  • 거래비용(세금, 스프레드, 슬리피지) 반영 백테스트

제안 출력 예시

종목코드 123456 / 현재가 9,850원 / 추천매수가 9,820~9,840원 / 목표가 10,800원 / 손절가 9,420원 / 권장수량 30주

근거: 스프레드 1틱, depth_buy_3 우수, 20거래일 +10% 확률 0.62(캘리브레이션), ATR 기반 손절(2.0 ATR)

본 페이지는 “자동 주문”이 아닌 사용자 수동 의사결정 보조를 전제로 하는 설계 문서 요약본입니다.
