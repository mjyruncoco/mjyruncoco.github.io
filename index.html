국장 전일 종가 2만원 이하·전일 Top 50 랭킹 종목 익일 매수 자동매매 개발 지시서

Executive Summary

본 문서는 “전일 종가 ≤ 20,000원” AND “전일 랭킹 Top 50” 조건 전략을 거래제도(정규장/동시호가), 세금(증권거래세/농특세), 슬리피지, 미체결, API 제한까지 반영해 검증하고 재현 가능한 코드베이스로 구현하기 위한 작업지시서입니다.

정규시장 시간은 호가접수 08:30~15:30, 매매거래 09:00~15:30 기준으로 설계하고, 랭킹은 KRX 거래 상·하위 50종목(거래대금/거래량) 구조를 1차 기준으로 둡니다.

전체 전제와 아키텍처

사실 전제와 공식 근거

  • 정보 시점: 전일 확정(EOD), 집행 시점: 익일 장중
  • 정규시장 시간 분리: 08:30~15:30(호가), 09:00~15:30(체결)
  • 세금 반영: KOSPI/KOSDAQ/KONEX 시장별 STT + KOSPI 농특세 옵션
  • 2만원 경계(틱 변화) 단위테스트 필수, VI 이벤트는 체결 지연 리스크로 로깅

권장 아키텍처

KRX EOD/Ranking Sources
  -> Raw Ingest
  -> Curated Store(Parquet)
  -> Ranker
  -> Signal Generator
  -> Backtest Engine / OMS Simulator
  -> Broker Adapter(Live)
  -> Orders/Fills/Positions
  -> Risk & Failsafe / Audit Logs

단계별 Codex 작업 지시서

  1. 데이터 수집/정제(raw→curated parquet, 무결성 검증)
  2. 랭킹(value/volume/mcap) + 동률 결정론 처리
  3. 신호 생성(close<=20000 and rank<=50, 익일 trade_date 고정)
  4. 백테스트 엔진(EOD 기본) + 비용/슬리피지 플러그인
  5. 포지션사이징/리스크(max_positions, daily_loss_limit)
  6. OMS 시뮬레이터(MKT/LMT/MLMT, 부분체결, 타임아웃, 재시도, 레이트리밋)
  7. 실계좌 어댑터(KIS 최소 루프 + 타 브로커 stub)
  8. CLI/테스트/운영문서(pytest, ruff/mypy 옵션)

테스트 계획(요약)

  • 랭킹 동률 결정론, 가격 경계값(20000 포함), 룩어헤드 방지
  • 틱 경계(19990 vs 20000), 시장별 세금 분기(KOSPI/KOSDAQ/KONEX)
  • OMS 상태머신/타임아웃/15초 윈도우 레이트리밋
  • KIS 토큰 만료/갱신 모킹 테스트

운영 체크리스트

  • 토큰 만료 전 갱신, 인증 실패 시 신규 주문 차단(safe stop)
  • 신호/주문/체결/리스크 로그를 JSONL로 append-only 저장
  • 일 손실한도 초과·미체결 장기화·API 오류 burst 알람
  • VI 이벤트 감지 시 주문정책 보수화 + 이벤트 기록
